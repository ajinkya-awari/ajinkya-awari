# Contributing

Thanks for taking an interest in this profile repository. Contributions should
make the profile clearer, more accessible, or more reliable without adding
tracking services or unverified claims.

## Before opening a change

- Keep the README factual and link only to public, verifiable resources.
- Keep generated SVGs self-contained; do not add JavaScript, remote images, or
  third-party statistics widgets.
- Do not add credentials, private repository names, personal contact data, or
  large generated artifacts.
- Run the local test suite and `git diff --check` before submitting a change.

## Pull requests

Explain the user-facing reason for the change and include the verification
commands you ran. Changes to the refresh workflow should also explain their
permissions and token behavior. Generated heatmap updates should be limited to
the generated asset and the workflow's normal commit should not modify source
files.

Please keep pull requests focused and use a clear, imperative commit message.
