# Security policy

This repository is a public profile and contains no application credentials or
private data. Please do not open a public issue containing a token, password,
private URL, or other sensitive information.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or a private security contact on
the repository if available. If neither option is enabled, open a minimal
public issue that says a private report is needed and does not include the
details. Include the affected file, reproduction steps, impact, and a
suggested mitigation in the private report.

The workflow is intended to use only GitHub's ephemeral repository token. Never
paste a personal access token into an issue, pull request, workflow file, or
commit.
